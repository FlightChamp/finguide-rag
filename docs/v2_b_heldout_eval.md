# FinGuide-RAG v2-B — 쉬운 설명 · 역검증 held-out 평가

> 공개 문서 기반 개인 포트폴리오 프로젝트의 평가 기록입니다. 어떤 금융기관의 공식 서비스나 평가가 아닙니다.

## 한 줄 요약

**사전 고정한 통과 기준 5개는 모두 통과했지만, 사람이 틀렸다고 본 쉬운 설명의 43%(6/14)를 역검증이 통과시켰다.**
교란(인위적으로 넣은 오류) 기반 안전 지표는 실제 생성 오류에 대한 안전성을 과대평가한다. 쉬운 설명은 직원 확인 없이 고객에게 내보낼 수준이 아니다.

## 평가 셋

- **성격**: A held-out v1 에서 사람 라벨이 Y 였던 초안 37건. *A 평가에서는 사용되었지만, B 의 simplifier/back-verifier 개발·프롬프트 조정·B 라벨링에는 사용되지 않은 task-specific held-out set* 이다. 프로젝트 전체에서 처음 보는 데이터가 아니다.
- B 가 평가하는 대상(쉬운 설명이 OK claim 의 뜻을 보존했는가)과 그 라벨은 이 단계에서 새로 만들었다.
- 37건 중 1건은 OK claim 이 없어 쉬운 설명 대상이 아니다 → **36건**.
- 사람 라벨: 쉬운 설명 Y 22 / N 14 · 조건 교란 Y 17 / N 4 · 수정본 Y 10. 라벨러 1인.

| 기준 | 결과 | 판정 |

[ ] 안은 Wilson 95% 신뢰구간. 조건 교란은 10건뿐이라 구간이 넓다(0.02–0.40).

## 기준에 없던 핵심 결과 — 자연 오류 놓침

통과 기준에는 '사람이 N 이라고 본 실제 생성 오류를 얼마나 잡는가'를 기준으로 넣지 않았다(보고만 하기로 함). 그런데 이 수치가 가장 나빴다.

| 지표 | 값 |
|---|---|
| 자연 오류 놓침 (사람 N 인데 PASS) | **6/14 = 0.43 [0.21–0.67]** |
| 자연 오류 탐지 | 8/14 = 0.57 [0.33–0.79] |
| 1차 PASS 중 사람 N (고객에게 보였을 틀린 설명) | **6/26 = 0.23 [0.11–0.42]** |
| 파이프라인 전체: 노출 32건(1차 PASS 26 + 수정 후 PASS 6) 중 사람 N | 6/32 = 0.19 [0.09–0.35] |
| 차단 (1회 수정 후에도 BLOCK) | 4/36 = 0.11 |

같은 지표가 개발 셋에서는 1/14 = 0.07 이었다. 개발 셋에서 조정한 규칙이 처음 보는 생성 오류에는 그만큼 일반화되지 않았다 — A 에서 범위 검사가 겪은 것과 같은 현상이다.

## 교란 놓침 (참고)

- NUM_COMPARATOR 1/6: hb_h074 '초과 → 이상'. 원문이 '5대 초과'이고 '대'가 개수 단위 목록(개·건·명·장·가지·곳·좌·매·종)에 없어 비교되지 않은 것으로 추정한다 (미확인).
- HEDGE_DROP 1/5: hb_h075 '있을 수 있습니다 → 있습니다'. 같은 claim 을 옮긴 조건 블록 문구에 헤지가 남아 claim 단위 검사가 통과했고, 문구 단위 헤지 검사도 걸리지 않았다 (원인 미확인 — 결과를 본 뒤라 여기서는 조사하지 않는다).
- 조건 교란 DROP 1/7: hcp_hb_h060 — 문장 첫머리 대상 한정('미성년자인 자녀의 인터넷뱅킹을 부모가 대리로 가입하려면')이 통째로 빠졌는데 LLM 이 다른 문구에 남아 있다고 판단.

## 이 결과가 말하는 것

1. **B 는 '직원 확인 보조'로 써야 한다.** 역검증 PASS 설명의 약 1/4(6/26)이 사람 기준으로 틀렸다. 화면 흐름의 마지막 단계(직원 확인)는 선택이 아니라 필수다.
2. **교란 지표만으로 안전을 주장하면 안 된다.** 교란 False Pass 0.02 와 자연 오류 놓침 0.43 은 같은 시스템의 수치다. 교란은 '우리가 상상한 오류'만 시험한다.
3. **개발 셋 성적(자연 오류 놓침 0.07)은 일반화되지 않았다.** A 의 cv-v2·범위 검사에 이어 세 번째로 같은 교훈이다.
4. 구조적 안전장치는 작동했다: CHECK 유입·claim 누락은 잡았고, 1회 수정이 오류를 숨긴 경우는 없었다.

## 한계

- **표본이 작다.** 사람 N 14건, 조건 교란 10건. 구간이 넓다.
- **라벨러 1인.** 판단 기준이 한 사람의 해석에 의존한다.
- **같은 모델 계열.** 쉬운 설명 생성, 조건 보존 검사, 조건 교란 생성이 모두 `gpt-4.1-mini` 다.
- **셋의 성격.** A 평가에 쓰인 초안이다. B 관점에서는 처음 보는 셋이지만 질문 분포는 A held-out v1 과 같다.
- **기준 설계.** 자연 오류 놓침을 통과 기준에 넣지 않았다. 사후에 기준을 바꾸지 않고, 이 문서에서 별도로 보고한다.
